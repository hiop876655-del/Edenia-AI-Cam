# AI Camera & Screen Recorder Pro (Native Flutter & Android)
تطبيق الكاميرا الذكية ومسجل الشاشة الاحترافي - بدون إنترنت 100%

## How to Build the APK (طريقة استخراج ملف الـ APK)

### 1. Locally on your Computer (على جهازك):
```bash
flutter pub get
flutter build apk --release
```
The APK will be generated at: `build/app/outputs/flutter-apk/app-release.apk`

### 2. Free Cloud Build via GitHub Actions (تجميع سحابي فوري ومجاني):
- Push this repo to your GitHub repository.
- Click on **Actions** tab -> **Build & Release AI Camera Pro APK**.
- Download your compiled **app-release.apk** instantly!
